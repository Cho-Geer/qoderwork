# AGENTS.md 新增第 8 节"验证原则（强制）"

**为什么**: 用户希望"先验证再下结论"的认知原则通用于所有任务（不限于 git/shell），且对弱模型（如 deepseek-v4-flash）也生效。原 AGENTS.md 无此规则，验证行为依赖模型自觉，弱模型几乎不会自发验证。

**改了什么**:
- `AGENTS.md` - 新增第 8 节"验证原则（强制）"：判别问句（"断言若错，最低成本如何发现"）+ 8 类断言检验清单表 + 4 类不强制验证的校准 + 4 条强制规则（含反规避条款：不得用"应该/通常/一般来说"掩盖未验证断言）
- `AGENTS.md` - 原"第 8 节 协作日志摘要"顺延为第 9 节，使两条强制规则（7 日志规范、8 验证原则）相邻，历史日志作为附录后移

**决策**: 写成可执行流程（if-then + 分类清单 + 反规避条款）而非模糊价值观，因弱模型对"要严谨"类价值观几乎无响应、对显式流程可作指令遵循执行。未选 MEMORY.md，因 AGENTS.md 每 session 自动加载、对所有模型生效，约束力更强；规则本身即"验证文化"，无需再在 memory 重复结论。
