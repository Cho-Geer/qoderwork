# 技能双语支持优化

**为什么**: 全部 skill 的触发 description 已有中英文，但多数正文没有明确的输出语言行为规则，无法保证中英文用户收到一致的可执行答复。

**改了什么**:
- `.agents/skills/*/SKILL.md` — 为 23 个 active skill 统一添加 `Language / 语言` 契约：跟随用户语言、按需双语、保留命令/API/路径/标识符和引用原文。
- `.agents/skills/skill-diagnosis-optimization/SKILL.md` — 增加语言契约诊断、自动修复和验证项，防止未来漂移。
- `documents/review/skill-audit-report.md` — 记录当前双语覆盖结论。

**决策**: 不机械翻译所有技术参考资料；以双语触发 description + 明确输出语言契约保证可发现性与交互支持，并避免重复文档造成上下文膨胀。
