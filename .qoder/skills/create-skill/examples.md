# create-skill examples

## Example 1: Debugging workflow skill

- User ask: `给我做一个排查线上报错的 skill`
- Trigger summary: `debug`, `investigate`, `排查`, `根因分析`
- Negative boundary: not for feature implementation

## Example 2: Review checklist skill

- User ask: `帮我做一个 PR 审核 skill`
- Trigger summary: `review PR`, `code review`, `审查`
- Negative boundary: not for auto-fixing code

## Example 3: Document conversion skill

- User ask: `我需要一个 Markdown 转 Word 的 skill`
- Trigger summary: `docx`, `markdown to word`, `文档转换`
- Negative boundary: not for spreadsheet or presentation tasks
