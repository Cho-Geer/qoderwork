## 维护说明

- **新增日志**：直接按 AGENTS.md §11.1 命名规范创建 `logs/YYYY-MM-DD-<主题>.md`，无需手动更新本索引
- **同步索引**：运行 logs-governance skill 的 §A Index Sync
- **归档旧日志**：运行 logs-governance skill 的 §B Archive
- **索引更新时机**：session 启动时、新增日志后、归档后
