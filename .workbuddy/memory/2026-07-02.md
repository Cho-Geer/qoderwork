### 关键发现

1. **MCP 工具返回格式标准**：
   ```json
   {
     "content": [{ "type": "text", "text": "..." }],
     "isError": false  // 或 true
   }
   ```

2. **自定义工具返回格式**：
   - `execute()` 可以返回字符串或对象
   - 返回值被框架包装为 `{ output: "...", title: "...", metadata: {} }`
   - 失败时设置 `metadata.error` 或 throw 错误

3. **失败检测逻辑**：
   - `detectFailure()`：检查 `metadata.error` 和 `ERROR_PATTERNS`
   - `detectSoftRejection()`：检查 `isError:true` 和结构化 JSON 的 `status:"rejected"` 或 `verified:false`
   - 只读工具只检查 `metadata.error`，不扫描 output 内容
