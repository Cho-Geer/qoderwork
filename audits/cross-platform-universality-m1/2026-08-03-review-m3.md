### BLOCKING-001: Phase 1 §3 row-1 baseline regex is broken as written (escaped pipes + quote-bracket scope)
- Location: `01-phase-runtime-import-fix.md:50`
- Current claim: `| 6 unique files contain static /home/zhaoge import | python -c "...re.compile(r'''from '/home/zhaoge\|require\('/home/zhaoge\|import\('/home/zhaoge''')" | 6 files |`
- Independent verification (V8): running the EXACT command prints `0 []`. - Required fix: rewrite the regex to match both quote styles and real alternation, e.g. `re.compile(r'from ["\']/home/zhaoge|require\(["\']/home/zhaoge|import\(["\']/home/zhaoge')`, and re-run to confirm it returns exactly the 6 target files (17 hits). The same pattern appears in the §7 step-2 scan (L152-162) — that one uses plain `/home/zhaoge` which is fine, but the §3 baseline row is the normative "verified baseline" and must be truthful.
